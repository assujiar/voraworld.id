## Commands

**Install Dependencies**

```console
npm i --loglevel=error
```

**Start Preview**

```console
npm run dev
```

**Render video**

```console
npx remotion render
```

**Upgrade Remotion**

```console
npx remotion upgrade
```

## VORA promo (60 s, 9:16)

Audio pipeline (run from this folder):

1. `python scripts/make_vo.py` with `KOKORO_DIR` pointing to Kokoro-82M ONNX (`model.onnx` + `voices.npz`). Voice blend and lines live in `src/timeline.json`.
2. `python scripts/synth_audio.py` builds the music and SFX stems (needs numpy, scipy, soundfile).
3. `python scripts/master_audio.py` mixes everything into `public/audio/soundtrack.wav` at -14 LUFS (needs pyloudnorm).
